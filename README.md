# Boucherie Hallem

Boutique en ligne et espace d'administration de la Boucherie Hallem (SARL Deligne), en Angular et Firebase.

- `npm start` : lance le site en local sur http://localhost:4200
- `npm test -- --watch=false` : lance les tests
- `npm run build` : prépare le site dans `dist/boucherie/browser`

`firestore.rules` contient les règles de sécurité, à publier dans la console Firebase.
Le déploiement sur Vercel est décrit par `vercel.json`.
